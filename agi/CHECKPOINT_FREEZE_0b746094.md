## Certification rule from this point

The cognitive implementation is considered frozen for each certification attempt. A certification attempt may create a fresh M and expose it to new experience, but may not change C, the public language bridge, or add domain-specific reasoning code after evaluation data are generated.

A successful unrestricted-certification claim requires evidence beyond bounded fixtures:

1. broad ordinary-language acquisition and multi-turn discourse from experience;
2. open-ended variable-length expression from arbitrary M-owned relational structure;
3. continued acquisition, transfer, correction, and action on domains generated after the implementation freeze;
4. evaluation material not encoded in implementation source and not used to patch C during the attempt;
5. no external language model or hidden semantic authority supplying the demonstrated cognition.

Failures are evidence. They must be traced to the earliest general architectural cause; tests must not be weakened to convert a failure into a pass.
