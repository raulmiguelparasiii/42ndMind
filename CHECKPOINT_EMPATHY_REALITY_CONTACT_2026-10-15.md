## Falsification controls

The same gate rejects three important alternatives:

```text
self_only_negative_control_rejected = true
spurious_correlation_rejected = true
broken_consequence_chain_rejected = true
```

`self_only`: the world still contains effects on another entity, but the queried orientation depends only on the subject's own state. The Stone motif is not instantiated.

`spurious correlation`: the other entity's state covaries observationally with context and response, but never varies independently with controls held fixed. Intervention support is zero, so correlation is not promoted to the required dependence relation.

`broken consequence chain`: the orientation genuinely depends on the non-self state, but evidence that an event/consequence actually changes that state is removed. Mere sensitivity is therefore insufficient.
